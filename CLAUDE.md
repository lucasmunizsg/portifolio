# Instruções do projeto (Portfólio)

Estas regras valem para qualquer trabalho feito neste repositório.

1. **Comentários em português**: toda alteração de código deve incluir comentários em português explicando o que foi mudado, especialmente quando a razão da mudança não é óbvia pela leitura do código.

2. **Commits e Pull Requests para revisão**: commits feitos na branch `preview` devem ter mensagens que destacam claramente as mudanças feitas. Ao abrir um Pull Request de `preview` para `main`, o campo de descrição ("Add a description") do GitHub deve detalhar, de forma organizada (por tópicos/seções), tudo o que foi atualizado — o objetivo é ter um histórico completo e didático que sirva de material de consulta para explicar as mudanças em entrevistas técnicas.
